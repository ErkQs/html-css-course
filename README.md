# Mini Shop Dashboard

Учебный frontend-проект на чистом JavaScript.

## Что умеет проект

- Загружает товары с API
- Показывает loading/error состояние
- Фильтрует товары по поиску
- Фильтрует товары по категории
- Сортирует товары по цене
- Добавляет товары в корзину
- Увеличивает и уменьшает количество товаров
- Удаляет товары из корзины
- Считает общую сумму корзины

## Технологии

- HTML
- CSS
- JavaScript
- Fetch API
- DOM
- Custom store
